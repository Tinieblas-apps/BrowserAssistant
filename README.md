# Browser Assistant

Программа для Windows: закладки, история, пароли и порядок в браузерах — Chrome, Edge, Opera, Яндекс.Браузер и
Firefox. Сделана для работы с экранным диктором NVDA: всё с клавиатуры, сообщения диктор читает сам. До версии 1.6.0
называлась «Закладки». Программа семейства «Тиневия», разработчик — Tinieblas.

## Что умеет

- Закладки всех браузеров — деревом папок и списком: правка, перенос, сортировка, удаление с отменой; перенос и
  копирование закладок из одного браузера в другой.
- Порядок: повторы, пустые папки, проверка ссылок (сам браузер открывает каждую закладку — с вашими входами на сайты
  и VPN), раскладка по сайтам, укорачивание названий, давно не открывавшиеся закладки.
- История браузера, сохранение закладок в файл и загрузка из файла.
- Пароли: какие сайты и логины сохранены (сами пароли программа не читает), добавление паролей в один или несколько
  браузеров, перенос паролей между браузерами.
- В Firefox — подписи картинкам без подписи, чтобы NVDA показывала их в режиме обзора.
- Аккаунт Тиневии: синхронизация закладок, настроек и проверок ссылок между вашими компьютерами (всё шифруется на
  компьютере). Без подписки можно смотреть, искать, открывать и сохранять копию; у нового аккаунта есть пробный срок.

## Как поставить

Скачайте `BrowserAssistant_portable.exe` из раздела
[Releases](https://github.com/Tinieblas-apps/BrowserAssistant/releases/latest) и запустите. Это не установщик: он
распаковывает папку программы туда, куда скажете, просит войти в аккаунт Тиневии (или зарегистрироваться), по желанию
делает ярлык на рабочем столе и горячую клавишу запуска и запускает программу. В Windows ничего не записывается;
удалить программу — удалить её папку.

Потом поставьте помощника в браузер — по шагам в программе: F1. Обновления — Ctrl+U в программе.

Файлы `.sig` — подписи: по ним программа проверяет, что файл настоящий.
